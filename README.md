# Paradise Nursery

## Project Overview
Paradise Nursery is a dynamic, interactive React-based e-commerce web application for a houseplant shop. It allows users to browse a variety of plants, view detailed plant information, add items to a shopping cart, and manage their cart by adjusting quantities or removing items. 

## Features
* **Landing Page:** Welcoming interface with a background image, company details, and a "Get Started" button.
* **Product Listing:** Browse at least 18 unique houseplants categorized into three distinct categories (Air Purifying, Aromatic, Succulents). 
* **State Management:** Utilizes Redux Toolkit for seamless cart management (add, remove, update quantities).
* **Shopping Cart:** Dynamically calculates total items, individual item costs, and the overall cart total.
* **Navigation:** A persistent navigation bar across the product and cart pages.

## Technologies Used
* React.js
* Redux Toolkit (State Management)
* HTML5 / CSS3
